# Init Check: heat-safe hours

A free, public-good tool. Pick any Philippine city and see the hourly heat index for the next days, colored by PAGASA's heat-index bands, with plain advice for kids, elders, pregnant women and outdoor workers. For parents, barangay health workers and outdoor workers. *Init* is Tagalog for heat.

Data: [Open-Meteo](https://open-meteo.com/) forecast API (free, no key) and PAGASA's published heat-index classification.
